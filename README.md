# 📒 Address Book

## 📌 Project Overview

The **Address Book** is a console-based application developed using **C programming** to manage contact information efficiently.

## ⚙️ Features

* Add new contacts
* Search contacts
* Edit existing contact details
* Delete contacts
* Display all saved contacts
* Store contact information using file handling

## 🛠️ Technologies & Concepts

* C Programming
* Structures
* Pointers
* Arrays
* Strings
* File Handling
* Modular Programming
* Input Validation

## 💡 Key Learning

This project helped me strengthen my understanding of **C programming, data structures, file handling, pointers, and modular application development**.

## 🎯 Challenges

* Managing contact data efficiently
* Implementing search, edit, and delete operations
* Maintaining data persistence using files
* Validating user input
